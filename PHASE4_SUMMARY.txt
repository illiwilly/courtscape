================================================================================
                           HOW TO USE PHASE 4
================================================================================

BUILD FOR PRODUCTION
──────────────────────────────────────────────────────────────────────────────
1. npm install               (Install dependencies)
2. npm run build             (Build React app into dist/)
3. npm start                 (Start server on port 3000)

DEVELOPMENT MODE
──────────────────────────────────────────────────────────────────────────────
npm run dev                  (Start backend + Vite dev server)
                             (Vite runs on :5173, backend on :3000)

TEST DATABASE CONNECTION
──────────────────────────────────────────────────────────────────────────────
npm run test:db              (Verify Databricks connectivity)

ACCESS THE APPLICATION
──────────────────────────────────────────────────────────────────────────────
After npm start:
  - http://localhost:3000    (Main application)
  
Pages available:
  - http://localhost:3000/search       (Judge/attorney search)
  - http://localhost:3000/law-firms    (Law firm directory)
  - http://localhost:3000/analytics    (Analytics dashboard)
